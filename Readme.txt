Template contains: 
-stm32f4xx standard peripherals library.
-.vscode/*.json files for vs code development.
-Makefile for ease of use.
-Linker for both RAM and FLASH -> default to ram.
-Startup file for running everything in RAM.
-Lelles library.

This project includes parts of the STM32F4 Standard Peripheral Library,
